DEEP-DIVE: THREE.JS & GLSL SHADERS

The 3D Real-Time Rendering Pipeline

How Three.js, GPU pipelines, and custom GLSL vertex/fragment shaders create a cinematic environment at 60 frames per second.

Pipeline Architecture

• Scene Graphs: Multiple layered scenes (`landing`, `projects`, `projectInterior`, `about`, `contact`).
• Camera Choreography: Perspective cameras interpolated via cubic hermite spline curves.
• Mesh Compression: Draco geometry reduces 3D polygon file sizes by 85%.
• Texture Streaming: KTX2 GPU texture compression bypasses CPU decompression.

Draco Compression KTX2 Textures Hermite Curves

ADAPTIVE UX ARCHITECTURE

Desktop 3D vs. Mobile "Lite" Engine

Ensuring zero users are left behind. Automatic device probing serves the optimal experience for high-end PCs, low-spec laptops, and smartphones.

🖥️ Desktop Mode (Full 3D WebGPU)

• Target: Desktop devices with dedicated or modern integrated GPUs.
• Features: Real-time Three.js scene, floating 3D phone model, spatial audio, particle dynamics, and immersive perspective cameras.
• Performance: Target 60 FPS with adaptive resolution scaling if GPU frame time exceeds 16.6ms.

WebGPU Spatial World 60 FPS
📱 Mobile / Lite Mode ("Project Slide View")

• Target: Smartphones, tablets, or devices without WebGPU support.
• Features: Clean horizontal slide deck, high-contrast typography, direct Chrome links, and zero GPU battery drain.
• Innovation: 100% feature parity without heavy WebGL overhead.

Zero Lag Battery Friendly Mobile Optimized
